# Settings Inspector

When you enter one of the settings sections from the **Settings** menu, the Inspector appears. This section is a list of options, each with its own label, current value, and editing method.

{{< img "/bgscan-settings.webp" "settings menu" >}}

- Select the option you want and press `Enter` to change its value.
- Pressing `d` shows the description and help for the selected option.
- Boolean options are shown as a Toggle.
- Some options appear only when their matching mode or protocol is selected.

Changes are saved to the settings file right away and you do not need to restart the scanner for them to take effect.
