# بخش تنظیمات

وقتی از منوی Settings وارد هر بخش تنظیمات شوید، صفحهٔ ویرایش تنظیمات را می‌بینید. این صفحه یک فهرست تب‌بندی‌شده از فیلدهاست که نام، مقدار فعلی و روش تغییر هر گزینه را نشان می‌دهد.

{{< img "/bgscan-settings.webp" "settings menu" >}}

- با انتخاب هر فیلد و زدن `Enter` مقدار آن را تغییر دهید.
- با `d` توضیح و راهنمای گزینهٔ انتخاب‌شده را ببینید.
- گزینه‌های روشن/خاموش به شکل Toggle نمایش داده می‌شوند.
- بعضی پروتکل‌ها فقط بعد از انتخاب یک حالت خاص، گزینه‌های بیشتری نشان می‌دهند.

تغییرات بدون نیاز به اجرای دوبارهٔ اسکنر، فوری روی دیسک ذخیره می‌شوند.
