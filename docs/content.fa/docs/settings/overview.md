# نمای کلی تنظیمات

همهٔ تنظیمات bgscan در فایل‌های سادهٔ TOML داخل پوشهٔ `settings/` هستند. همین گزینه‌ها از داخل بخش Settings برنامه هم در دسترس‌اند و تغییرات آن‌جا خودکار روی دیسک ذخیره می‌شوند.

## فایل‌های تنظیمات

| فایل | کاربرد |
|---|---|
| `settings/general_settings.toml` | کنترل کلی اسکن و حالت Pipeline |
| `settings/writer_settings.toml` | بافر نتیجه‌ها و نوشتن روی دیسک |
| `settings/icmp_settings.toml` | تنظیمات پروب ICMP |
| `settings/tcp_settings.toml` | تنظیمات اتصال TCP |
| `settings/http_settings.toml` | تنظیمات HTTP/HTTPS/HTTP3 |
| `settings/xray_settings.toml` | تنظیمات تست Xray |
| `settings/dns_settings.toml` | تنظیمات Resolver، DNSTT و Slipstream |

## دو روش برای تغییر تنظیمات

- **فایل‌های TOML:** هر فایل `settings/*.toml` را با یک ویرایشگر متن باز کنید، مقدارها را تغییر دهید، ذخیره کنید و bgscan را دوباره اجرا کنید. این روش برای نگه‌داری تنظیمات در Git هم مناسب است.
- **بخش Settings داخل برنامه:** bgscan را باز کنید، از منوی اصلی وارد **Settings** شوید، دستهٔ مورد نظر را انتخاب کنید و روی هر فیلد `Enter` بزنید. تغییرات همان لحظه روی دیسک ذخیره می‌شوند.

بعضی گزینه‌ها بسته به انتخاب شما ظاهر می‌شوند؛ مثلاً گزینه‌های TLS فقط وقتی HTTPS را انتخاب کنید دیده می‌شوند و تنظیمات DNSTT یا Slipstream فقط وقتی آن پروب‌ها فعال باشند.

## مقدار پیش‌فرض و اعتبارسنجی

مقدارهای پیش‌فرض داخل خود bgscan هستند. اگر فایل تنظیماتی وجود نداشته باشد، در اولین اجرا با مقدارهای پیش‌فرض ساخته می‌شود. اگر یک گزینه داخل فایل جا افتاده باشد، همان مقدار پیش‌فرض استفاده می‌شود. اما فایلی که وجود دارد ولی قابل خواندن نیست خطا محسوب می‌شود.

هنگام شروع برنامه، همهٔ تنظیمات بررسی می‌شوند. مقدارهای خارج از محدوده با مقدار پیش‌فرض جایگزین و در لاگ ثبت می‌شوند؛ پس یک ویرایش اشتباه باعث خراب‌شدن اسکن نمی‌شود.

فایل‌های `settings/*.toml.default` داخل مخزن فقط نسخهٔ مرجع تنظیمات پیش‌فرض هستند و bgscan هنگام اجرا آن‌ها را نمی‌خواند.
