# شروع کار با bgscan

توی این بخش با محیط برنامه آشنا می‌شید و یاد می‌گیرید چطور اولین اسکن رو اجرا کنید.

## اجرای bgscan

وارد پوشه‌ای بشید که برنامه رو توش نصب کردید و اجراش کنید:

- **Windows:** روی `bgscan.exe` دوبار کلیک کنید یا توی PowerShell دستور `.\bgscan.exe` رو اجرا کنید.
- **Linux/macOS/Termux:** توی ترمینال دستور `./bgscan` رو اجرا کنید.

## منوی اصلی

وقتی bgscan رو اجرا می‌کنید، اول صفحه Splash نمایش داده می‌شه و بعد برنامه چند بررسی اولیه انجام می‌ده. توی این مرحله، تنظیمات بررسی می‌شن، هسته داخلی Xray راه می‌افته، کتابخانه اختیاری Slipstream بررسی می‌شه و تنظیمات تونل‌های DNS هم مورد بررسی قرار می‌گیرن.

بعد از تموم شدن بررسی‌ها، `Enter` رو بزنید تا وارد برنامه بشید. فقط خطا در خوندن تنظیمات مانع اجرای برنامه می‌شه.

منوی اصلی این گزینه‌ها رو داره:

| گزینه | توضیح |
|--------|-------------|
| **Run Scan** | شروع اسکن شبکه |
| **IP Files** | انتخاب و مدیریت فایل‌های IP برای اسکن |
| **Result Files** | مشاهده و مدیریت نتایج ذخیره‌شده |
| **Xray Outbound** | مدیریت تنظیمات پروکسی Xray |
| **DNS Tunneling** | تنظیم و مدیریت اتصال‌های تونل DNS |
| **Settings** | تنظیم پارامترهای اسکن و سایر ترجیحات |
| **Logs** | مشاهده لاگ‌های برنامه و اسکن |

## کلیدهای حرکت

برای جابه‌جایی توی منوها از این کلیدها استفاده کنید:

- **کلیدهای جهت‌نما ↑ ↓:** حرکت بین گزینه‌ها
- **Enter:** انتخاب گزینه‌ای که هایلایت شده
- **b یا Esc:** برگشت به صفحه قبل
- **q:** خروج از منوی اصلی با تأیید
- **Ctrl+C:** خروج فوری از برنامه

> **نکته:** توی بیشتر صفحه‌ها با زدن `?` می‌تونید کلیدهای میان‌بر همون صفحه رو ببینید.

## اولین اسکن

برای اینکه اولین اسکن رو اجرا کنید، این مراحل رو انجام بدید:

1. bgscan رو از پوشه نصب اجرا کنید.
2. گزینه **Run Scan** رو انتخاب کنید و `Enter` بزنید.
3. یه فهرست IP انتخاب کنید. برای شروع، می‌تونید از یکی از فهرست‌های داخلی مثل `cloudflare_IPv4` استفاده کنید.
4. نوع اسکن رو انتخاب کنید. برای یه تست ساده اتصال، `tcp` گزینه مناسبیه.
5. `Enter` رو بزنید تا اسکن شروع بشه.
6. صبر کنید تا اسکن تموم بشه.
7. نتیجه‌ها رو همون‌جا ببینید یا بعداً از منوی اصلی وارد بخش **Result Files** بشید.
