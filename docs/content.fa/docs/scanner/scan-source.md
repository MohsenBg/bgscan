# ورودی اسکن

قبل از شروع اسکن، باید مشخص کنید bgscan کدوم آدرس‌ها رو بررسی کنه. برای این کار، از **Main Menu → Run Scan** وارد انتخاب ورودی اسکن بشید. اینجا دو گزینه دارید:

| کلید | گزینه | توضیح |
|---|---|---|
| `i` | IP List | انتخاب فایل از فهرست‌های IP |
| `r` | Result List | انتخاب فایل نتیجه از یه اسکن قبلی |

---

## IP List

با انتخاب **IP List**، فهرست فایل‌های IP باز می‌شه. فایل موردنظرتون رو از پوشه `ips/` انتخاب کنید تا bgscan آدرس‌های داخل اون رو برای اسکن استفاده کنه.

این گزینه برای وقتیه که می‌خواید یه مجموعه IP جدید رو بررسی کنید. مثلاً رنج‌های یه CDN، آدرس‌های مربوط به یه کشور یا فهرستی که خودتون آماده کردید.

برای آشنایی با نحوه وارد کردن و مدیریت فایل‌ها، صفحه [فهرست‌های IP](./ip-files.md) رو ببینید.

---

## Result List

با انتخاب **Result List**، فهرست فایل‌های نتیجه باز می‌شه. یکی از فایل‌هایی رو که قبلاً ذخیره کردید انتخاب کنید تا bgscan آدرس‌های داخل اون رو دوباره اسکن کنه.

این روش وقتی به کار میاد که بخواید روی نتیجه‌های یه اسکن قبلی، بررسی دقیق‌تری انجام بدید یا نوع دیگه‌ای از اسکن رو اجرا کنید. مثلاً می‌تونید IPهایی رو که از پیش‌اسکن ICMP عبور کرده‌ان، برای اسکن Xray انتخاب کنید.

برای آشنایی با ساختار این فایل‌ها، صفحه [فایل‌های نتیجه](./result-files.md) رو ببینید.

---

## قدم بعدی

بعد از انتخاب فایل، bgscan شما رو به مرحله انتخاب **Scan Type** می‌بره. اینجا مشخص می‌کنید کدوم پروب روی آدرس‌های انتخاب‌شده اجرا بشه.

توضیحات هر پروب رو در صفحه [انواع اسکن](./scan-types.md) بخونید.
