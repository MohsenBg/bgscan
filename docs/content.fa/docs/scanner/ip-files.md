# فهرست‌های IP

اسکنر هدف‌هایش را از فایل‌های فهرست IP می‌خواند. قبل از این‌که بتوانید یک فهرست را برای اسکن استفاده کنید، باید آن را آماده و وارد bgscan کنید.

## آماده‌کردن فایل برای ورود

فایلی که وارد می‌کنید باید یک فایل متنی ساده با پسوند `.txt` باشد و **در هر خط فقط یک آیتم** داشته باشد. bgscan هم IPv4 و هم IPv6 را قبول می‌کند؛ هم آدرس تکی و هم محدوده‌های CIDR.

| قالب | نمونه |
| --- | --- |
| یک آدرس IPv4 | `192.168.1.1` |
| محدودهٔ IPv4 | `10.0.0.0/24` |
| یک آدرس IPv6 | `2606:4700::6810:85e5` |
| محدودهٔ IPv6 | `2606:4700::/32` |

**قوانین:**

- در هر خط فقط یک آیتم بنویسید.
- خط‌های خالی و خط‌هایی که آدرس یا CIDR معتبر نباشند، بی‌سروصدا نادیده گرفته می‌شوند.
- فایل از کامنت پشتیبانی نمی‌کند؛ خط‌هایی که با `#` شروع شوند هم قابل پردازش نیستند و نادیده گرفته می‌شوند.
- فاصلهٔ اول و آخر هر خط به‌صورت خودکار حذف می‌شود.

> **نکته دربارهٔ محدوده‌های بزرگ IPv6:** یک پیشوند `/32` در IPv6 بیشتر از `2^96` آدرس دارد. bgscan محدوده‌های CIDR را هنگام اسکن باز می‌کند، اما اسکن کامل چنین محدوده‌ای عملاً ممکن نیست. برای محدودکردن تعداد IPها، گزینهٔ `max_ips_to_test` را در [تنظیمات عمومی](../settings/general.md) مشخص کنید.

### نمونهٔ فایل

```text
192.168.1.1
10.0.0.0/24
172.16.50.100
203.0.113.0/28
2606:4700::6810:85e5
2606:4700::/32
```

## فهرست‌های آماده

bgscan چند فهرست آماده را داخل پوشهٔ `ips/` قرار می‌دهد. این فهرست‌ها خودکار بارگذاری می‌شوند و بدون تنظیم اضافه برای اسکن آماده‌اند.

| نام | توضیح |
| --- | --- |
| `akamai_IPv4` | محدوده‌های IPv4 مربوط به CDN آکامای |
| `aws_IPv4` | محدوده‌های IPv4 سرویس‌های Amazon Web Services |
| `azure_IPv4` | محدوده‌های IPv4 Microsoft Azure |
| `bunny_IPv4` | محدوده‌های IPv4 CDN بانی |
| `cloudflare_IPv4` | محدوده‌های IPv4 کلودفلر |
| `cloudflare_IPv6` | محدوده‌های IPv6 کلودفلر |
| `cloudflare_ipv6_known` | محدوده‌های شناخته‌شده و قابل‌اعتماد IPv6 کلودفلر |
| `cloudflare_common_IPv6` | محدوده‌های رایج IPv6 کلودفلر |
| `cloudflare_full_IPv6` | محدوده‌های کامل IPv6 کلودفلر |
| `fastly_IPv4` | محدوده‌های IPv4 CDN فستلی |
| `gcore_IPv4` | محدوده‌های IPv4 G-Core Labs |
| `google_IPv4` | محدوده‌های IPv4 گوگل |
| `iran_IPv4` | آدرس‌های IPv4 ایران |
| `pub_dns_IPv4` | آدرس‌های IPv4 سرورهای DNS عمومی |

این فایل‌ها همان فرمت CSV داخلی فهرست‌های واردشده را دارند و مثل هر فایل دیگری می‌توانید آن‌ها را تغییر نام دهید یا حذف کنید.
