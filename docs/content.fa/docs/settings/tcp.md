# تنظیمات TCP

> 💡 **نکته:** لازم نیست فایل TOML رو دستی ویرایش کنید. می‌تونید تنظیمات رو مستقیماً از داخل خود BGScan تغییر بدید.
>
> از منوی اصلی وارد **Settings → TCP Settings** بشید و گزینه‌ها رو با Inspector داخل TUI تنظیم کنید.

فایل تنظیمات: `settings/tcp_settings.toml`

پروب TCP به پورت مشخصی روی هر هدف وصل می‌شه و زمان برقراری Handshake رو ثبت می‌کنه. در این مرحله، ارتباطی در سطح پروتکل‌های کاربردی برقرار نمی‌شه.

## مرجع سریع

| تنظیم | پیش‌فرض | محدوده | توضیح |
|---|---|---|---|
| `port` | `443` | ۱ تا ۶۵۵۳۵ | پورت TCP مقصد |
| `timeout` | `2000` | ۱۰۰ تا ۳۰۰۰۰ | حداکثر زمان انتظار برای اتصال، به میلی‌ثانیه |
| `workers` | وابسته به پلتفرم | ۱ تا ۵۰۰۰ | تعداد تلاش‌های هم‌زمان برای اتصال |
| `tries` | `1` | ۱ تا ۱۰ | تعداد تلاش برای هر هدف |
| `output_prefix` | `"tcp_"` | ندارد | پیشوند نام فایل نتیجه |

## پورت

```toml
port = 80
```

پورت TCPای که روی هر هدف بررسی می‌شه. پورت‌های رایج عبارت‌اند از:

- `80` برای HTTP
- `443` برای HTTPS
- `22` برای SSH

البته می‌تونید هر پورتی رو که می‌خواید بررسی کنید، وارد کنید.

## Timeout

```toml
timeout = 3000
```

حداکثر زمانی که پروب برای برقراری اتصال و تکمیل Handshake منتظر می‌مونه، برحسب میلی‌ثانیه. اگه اتصال در این مدت برقرار نشه، تلاش ناموفق در نظر گرفته می‌شه.

مقادیر پیشنهادی برای شروع:

- `1000-3000` میلی‌ثانیه برای شبکه‌های محلی
- `5000-10000` میلی‌ثانیه برای شبکه‌های دور یا ناپایدار

## Workerها

```toml
workers = 200
```

تعداد اتصال‌هایی که به‌صورت هم‌زمان بررسی می‌شن. هر Worker یک سوکت جداگانه باز می‌کنه. بنابراین، با افزایش تعداد Workerها، باید محدودیت File Descriptorهای سیستم رو هم در نظر بگیرید.

مقادیر پیشنهادی برای شروع:

- `50-100` برای سیستم‌هایی با منابع محدود
- `200-500` برای استفاده معمول
- `500-1000` برای اسکن با توان بالاتر

## تعداد تلاش

```toml
tries = 1
```

تعداد تلاش‌هایی که برای هر هدف انجام می‌شه. در صورت Timeout، اتصال دوباره امتحان می‌شه. اما خطاهای فوری، مثل `connection refused`، باعث می‌شن هدف همون لحظه ناموفق در نظر گرفته بشه. این رفتار کمک می‌کنه اسکن محدوده‌هایی که بیشتر پورت‌هاشون بسته‌ست، سریع‌تر تموم بشه.

حداقل مقدار این گزینه `1` هست. بنابراین، اولین تلاش رو نمی‌شه غیرفعال کرد.

## پیشوند خروجی

```toml
output_prefix = "tcp_"
```

پیشوند نام فایل‌های نتیجه‌ای رو مشخص می‌کنه که این پروب تولید می‌کنه. فایل‌ها در مسیر `result/tcp/` ذخیره می‌شن.
