# Inspector تنظیمات

وقتی از منوی **Settings** وارد یکی از بخش‌های تنظیمات می‌شید، Inspector نمایش داده می‌شه. این بخش فهرستی از گزینه‌هاست که هرکدوم برچسب، مقدار فعلی و روش ویرایش خودشون رو دارن.

{{< img "/bgscan-settings.webp" "settings menu" >}}

- گزینه موردنظرتون رو انتخاب کنید و `Enter` بزنید تا مقدارش رو تغییر بدید.
- با زدن `d` می‌تونید توضیحات و راهنمای گزینه انتخاب‌شده رو ببینید.
- گزینه‌های بولی یا Boolean به‌صورت Toggle نمایش داده می‌شن.
- بعضی گزینه‌ها فقط وقتی نمایش داده می‌شن که حالت یا پروتکل مربوط به اون‌ها انتخاب شده باشه.

تغییرات بلافاصله در فایل تنظیمات ذخیره می‌شن و برای اعمالشون نیازی به راه‌اندازی مجدد اسکنر نیست.
