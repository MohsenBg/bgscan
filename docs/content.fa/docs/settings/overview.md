# نمای کلی تنظیمات

تنظیمات BGScan در فایل‌های TOML داخل پوشه `settings/` نگه‌داری می‌شن. بیشتر تنظیمات اسکن و رابط کاربری رو می‌تونید از داخل خود برنامه هم تغییر بدید. تغییراتی که از طریق Inspector انجام می‌شن، به‌صورت خودکار روی دیسک ذخیره می‌شن.

## فایل‌های تنظیمات

| فایل | کاربرد |
|---|---|
| `settings/general_settings.toml` | تنظیمات کلی اسکن و حالت اجرای اسکن |
| `settings/writer_settings.toml` | تنظیم بافر و ذخیره نتیجه‌ها روی دیسک |
| `settings/icmp_settings.toml` | تنظیمات پروب ICMP |
| `settings/tcp_settings.toml` | تنظیمات اتصال TCP |
| `settings/http_settings.toml` | تنظیمات پروب HTTP، HTTPS و HTTP/3 |
| `settings/xray_settings.toml` | تنظیمات اسکن Xray |
| `settings/dns_settings.toml` | تنظیمات اسکن DNS و تونل‌های DNS |
| `settings/ui_settings.toml` | تنظیمات تم، پس‌زمینه، انیمیشن، حداکثر ردیف‌های جدول و سطح لاگ |

## دو روش برای تغییر تنظیمات

- **ویرایش فایل‌های TOML:** فایل موردنظرتون رو از پوشه `settings/` با یک ویرایشگر متن باز کنید، مقدارها رو تغییر بدید و ذخیره کنید. برای اعمال تغییرات، BGScan رو دوباره اجرا کنید. این روش برای مدیریت تنظیمات با Version Control هم مناسبه.
- **استفاده از Inspector داخل برنامه:** BGScan رو اجرا کنید، از منوی اصلی وارد **Settings** بشید و بخش موردنظرتون رو انتخاب کنید. با زدن `Enter` روی هر گزینه می‌تونید مقدارش رو تغییر بدید. تغییرات همون لحظه روی دیسک ذخیره می‌شن. تنظیمات رابط کاربری، مثل تم و سطح لاگ، هم بدون راه‌اندازی مجدد اعمال می‌شن.

Inspector فقط گزینه‌های مرتبط با تنظیمات فعلی رو نمایش می‌ده. برای مثال، گزینه‌های TLS مربوط به HTTP فقط زمانی نمایش داده می‌شن که HTTPS انتخاب شده باشه.

## مقدارهای پیش‌فرض و اعتبارسنجی

مقدارهای پیش‌فرض داخل خود BGScan تعریف شدن. اگه فایل تنظیمات وجود نداشته باشه، برنامه در اولین اجرا اون رو با مقدارهای پیش‌فرض می‌سازه. فیلدهایی هم که در فایل وجود ندارن، مقدار پیش‌فرض خودشون رو می‌گیرن.

اما اگه فایل وجود داشته باشه و محتوای اون قابل Parse نباشه، برنامه خطا می‌ده و بی‌سروصدا به مقدارهای پیش‌فرض برنمی‌گرده.

هنگام شروع برنامه، تنظیمات بارگذاری‌شده اعتبارسنجی می‌شن. اگه مقداری خارج از محدوده مجاز باشه، با مقدار پیش‌فرض جایگزین می‌شه و این موضوع در بررسی‌های اولیه برنامه گزارش می‌شه. به این ترتیب، یک مقدار نامعتبر معمولاً باعث از کار افتادن برنامه نمی‌شه.

مقدارهای اصلاح‌شده ابتدا فقط در حافظه تغییر می‌کنن. برای ذخیره اون‌ها در فایل، باید بخش مربوطه رو از طریق Inspector ذخیره کنید.

## تنظیمات تونل DNS

تنظیمات پروتکل‌های تونل DNS شامل DNSTT، VayDNS، Slipstream، MasterDNS، StormDNS و TheFeed در فایل‌های TOML جداگانه‌ای داخل پوشه `assets/dns-tunneling/` ذخیره می‌شن، نه در `dns_settings.toml`.

برای ساخت و مدیریت این تنظیمات، از داخل برنامه به مسیر زیر برید:

**Main Menu → DNS Tunneling**
