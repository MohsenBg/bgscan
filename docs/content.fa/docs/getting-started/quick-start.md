# شروع کار با bgscan

در این راهنما می‌بینید بعد از نصب چه چیزهایی در اختیار دارید و چطور اولین اسکن خود را اجرا کنید.

## اجرای bgscan

به پوشه‌ای بروید که bgscan را در آن نصب کرده‌اید و برنامه را اجرا کنید:

- **Windows:** روی `bgscan.exe` دو بار کلیک کنید یا در PowerShell دستور `./bgscan.exe` را اجرا کنید.
- **Linux، macOS و Termux:** در ترمینال دستور `./bgscan` را بزنید.

## منوی اصلی

بعد از اجرای bgscan، منوی اصلی را با این گزینه‌ها می‌بینید:

| گزینه | کاربرد |
| -------- | -------- |
| **Run Scan** | شروع یک اسکن جدید |
| **IP Files** | مدیریت و انتخاب فایل‌های IP |
| **Result Files** | دیدن و مدیریت نتیجه‌های ذخیره‌شده |
| **Settings** | تغییر تنظیمات اسکن |
| **Xray Outbounds** | مدیریت تنظیمات Proxyهای Xray |
| **Logs** | دیدن لاگ‌های برنامه و اسکن |

## حرکت در برنامه

برای جابه‌جا شدن در منوها از این کلیدها استفاده کنید:

- **کلیدهای جهت‌نما** (↑ ↓) — بالا و پایین رفتن بین گزینه‌ها
- **Enter** — انتخاب گزینه‌ای که روی آن هستید
- **b** یا **Esc** — برگشت به صفحهٔ قبلی
- **q** — خروج از برنامه

> 💡 **نکته:** هر وقت خواستید، با زدن `q` می‌توانید bgscan را با خیال راحت ببندید.

## اجرای اولین اسکن

1. bgscan را از پوشهٔ نصب اجرا کنید.
2. گزینهٔ **Run Scan** را انتخاب کنید و `Enter` بزنید.
3. یک فهرست IP انتخاب کنید. برای شروع می‌توانید از فهرست آماده‌ای مثل `cloudflare_IPv4` استفاده کنید.
4. نوع اسکن را انتخاب کنید. برای یک تست سریع اتصال، `tcp` گزینهٔ خوبی است.
5. برای شروع اسکن `Enter` بزنید.
6. صبر کنید تا اسکن تمام شود.
7. نتیجه‌ها را همان‌جا روی صفحه ببینید یا بعداً از منوی اصلی وارد **Result Files** شوید.
