# تنظیمات Xray

> 💡 **نکته:** از **Settings → Xray Settings** می‌توانید این گزینه‌ها را داخل برنامه تغییر دهید.

فایل تنظیمات: `settings/xray_settings.toml`

این فایل بخش بررسی Outboundهای Xray را کنترل می‌کند؛ یعنی اتصال و پهنای باند سرورهای راه دور را آزمایش می‌کند.

## خلاصهٔ گزینه‌ها

| گزینه | پیش‌فرض | توضیح |
|---|---:|---|
| `timeout` | `4000` | بیشترین زمان تست اتصال، میلی‌ثانیه |
| `workers` | `32` | تعداد تست هم‌زمان |
| `connectivity_test_type` | `0` | ۰ اتصال، ۱ دانلود، ۲ آپلود، ۳ هر دو |
| `download_speed` | `100` | حداقل سرعت دانلود قابل قبول، Kbps |
| `upload_speed` | `50` | حداقل سرعت آپلود قابل قبول، Kbps |
| `prefix_output` | `"xray_"` | پیشوند فایل‌های نتیجه |
| `pre_scan_type` | `"tcp"` | بررسی اولیه: `none`، `icmp`، `tcp` یا `http` |

## Timeout

```toml
timeout = 6000
```

بیشترین زمان انتظار برای تمام‌شدن یک تست Xray است. هدفی که در این زمان پاسخ ندهد ناموفق حساب می‌شود.

- `3000-6000` برای شبکه‌های مطمئن
- `6000-12000` برای شبکه‌های دور یا ناپایدار

## Workers

```toml
workers = 32
```

تعداد تست‌های اتصال هم‌زمان. مقدار بیشتر سرعت تست را بالا می‌برد، اما پهنای باند و CPU بیشتری مصرف می‌کند.

- `8-16` برای منابع محدود
- `16-32` برای استفادهٔ معمول
- `32-64` برای تست پرسرعت

## Connectivity Test Type

```toml
connectivity_test_type = 0
```

- `0` — فقط بررسی اتصال
- `1` — فقط سرعت دانلود
- `2` — فقط سرعت آپلود
- `3` — تست دانلود و آپلود

## Download Speed

```toml
download_speed = 100
```

حداقل سرعت دانلود قابل قبول بر حسب Kbps است. پروب به اندازهٔ `download_speed * timeout` داده جابه‌جا می‌کند و اگر سرعت اندازه‌گیری‌شده کمتر باشد، هدف را ناموفق می‌داند. فقط برای نوع تست `1` یا `3` استفاده می‌شود.

- `50-200` برای تست پهنای باند متوسط
- `200-1000` برای تست پهنای باند بالا

## Upload Speed

```toml
upload_speed = 50
```

حداقل سرعت آپلود قابل قبول بر حسب Kbps است و مثل `download_speed` کار می‌کند. فقط در نوع تست `2` یا `3` استفاده می‌شود.

- `25-100` برای تست متوسط
- `100-500` برای تست بالا

## Prefix Output

```toml
prefix_output = "xray_"
```

پیشوند نام همهٔ فایل‌های خروجی این بخش است و برای جداکردن نتیجه‌های اسکن‌های هم‌زمان مفید است.

## Pre-scan Type

```toml
pre_scan_type = "none"
```

یک بررسی ارزان‌تر است که قبل از Xray اجرا می‌شود. هدفی که این مرحله را رد کند به Xray نمی‌رسد.

- `none` — بررسی اولیه را رد کن و مستقیم Xray را اجرا کن
- `icmp` — Ping ICMP هدف را بررسی کن
- `tcp` — اتصال TCP به پورت هدف را بررسی کن
- `http` — درخواست HTTP/HTTPS به هدف بفرست
