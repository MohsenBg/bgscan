# اسکنر

اسکنر پروب‌های مختلف رو روی فهرستی از آدرس‌های IP اجرا می‌کنه. بیشتر اسکن‌ها به‌تنهایی اجرا می‌شن، اما بعضی‌ها می‌تونن قبل از اسکن اصلی یه مرحله بررسی اولیه هم داشته باشن.

برای تونل‌های DNS می‌شه یه مرحله پیش‌اسکن با ریزالور اضافه کرد. اسکن Xray هم می‌تونه قبل از شروع، هدف‌ها رو با TCP، ICMP یا HTTP بررسی کنه. به این ترتیب، فقط هدف‌هایی که پاسخ می‌دن به مرحله بعد می‌رسن و لازم نیست وقت صرف بررسی‌های کندتر روی بقیه بشه.

موتور اسکنر از زنجیره‌های طولانی‌تر هم پشتیبانی می‌کنه، اما رابط ترمینالی برنامه یا TUI فعلاً فقط همین ترکیب‌های پیش‌اسکن رو در اختیارتون می‌ذاره.

- [منبع اسکن](./scan-source/): آدرس‌های هدف از کجا میان
- [انواع اسکن](./scan-types/): هر پروب چه کاری انجام می‌ده
- [مراحل اسکن](./scan-pipeline/): مرحله‌های اسکن چطور به هم وصل می‌شن
- [فهرست‌های IP](./ip-files/): فایل‌های ورودی اسکن
- [فایل‌های نتیجه](./result-files/): فایل‌های خروجی اسکن
- [Outboundهای Xray](./xray-outbound/): قالب‌های Outbound برای اسکن با Xray
