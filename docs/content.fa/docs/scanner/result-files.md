# فایل‌های نتیجه

بعد از تمام‌شدن اسکن، bgscan IPهای پیدا‌شده و اطلاعات مربوط به آن‌ها را در فایل‌های نتیجه ذخیره می‌کند. این فایل‌ها بر اساس زمان ساخت مرتب می‌شوند و از داخل TUI می‌توانید آن‌ها را ببینید، تغییر نام دهید یا حذف کنید.

## دیدن فایل‌های نتیجه

برای بازکردن فهرست نتیجه‌ها به **Main Menu → Result Files** بروید.

این جدول همهٔ فایل‌های نتیجه را از جدیدترین به قدیمی‌ترین نشان می‌دهد:

| ستون | توضیح |
| --- | --- |
| File Name | نام فایل بدون پسوند `.csv` |
| Created Time | زمان ساخت یا آخرین تغییر فایل |
| Type | نوع اسکن سازندهٔ فایل (`icmp`، `tcp`، `http` و...) |
| Size | حجم فایل روی دیسک |

دو کلید در این صفحه کاربرد دارند:

| کلید | کار |
| --- | --- |
| `r` | تغییر نام فایل انتخاب‌شده |
| `x` | حذف دائمی فایل انتخاب‌شده |

#### بازکردن فایل نتیجه

با زدن `Enter` روی هر فایل، IP Viewer باز می‌شود. در این بخش هدف‌های پیدا‌شده و ستون‌هایی را می‌بینید که Schema همان نوع اسکن تعریف کرده است. نتیجه‌های ICMP، TCP، HTTP، DNS، DNSTT، VayDNS و Slipstream زمان پاسخ و اطلاعات مخصوص خودشان را نشان می‌دهند. نتیجه‌های Xray علاوه بر این‌ها سرعت دانلود و آپلود را هم دارند.

## محل ذخیره

فایل‌های نتیجه در پوشهٔ `result/` و در کنار باینری bgscan ذخیره می‌شوند. هر نوع اسکن پوشهٔ خودش را دارد:

```text
<bgscan-root>/
└── result/
    ├── icmp/
    ├── tcp/
    ├── http/
    ├── xray/
    ├── dns_resolver/
    ├── dnstt/
    ├── vaydns/
    └── slipstream/
```

هر پوشه فایل‌های `.csv` مربوط به همان نوع اسکن را نگه می‌دارد. این پوشه‌ها هنگام اجرای اسکن خودکار ساخته می‌شوند و لازم نیست آن‌ها را دستی بسازید.

## نام فایل‌ها

نام فایل از پیشوند تنظیم‌شدهٔ نوع اسکن و زمان ساخته‌شدن آن تشکیل می‌شود:

```text
<prefix><YYYYMMDD_HHMMSS>.csv
```

هر نوع اسکن یک پیشوند پیش‌فرض دارد:

| نوع اسکن | پیشوند | نمونهٔ نام فایل |
| --- | --- | --- |
| ICMP | `icmp_` | `icmp_20240711_143022.csv` |
| TCP | `tcp_` | `tcp_20240711_143022.csv` |
| HTTP | `http_` | `http_20240711_143022.csv` |
| Xray | `xray_` | `xray_20240711_143022.csv` |
| DNS Resolver | `dns_` | `dns_20240711_143022.csv` |
| DNSTT | `dns_tun_` | `dns_tun_20240711_143022.csv` |
| VayDNS | `dns_tun_` | `dns_tun_20240711_143022.csv` |
| Slipstream | `dns_tun_` | `dns_tun_20240711_143022.csv` |

پیشوند هر اسکن در فایل تنظیمات خودش مشخص می‌شود. برای اطلاعات بیشتر [نمای کلی تنظیمات](../settings/overview.md) را ببینید.

## فرمت فایل

فایل‌های نتیجه CSV ساده و بدون ردیف عنوان هستند. هر ردیف یک هدف پاسخ‌گو است و طبق Schema همان نوع اسکن نوشته می‌شود. همهٔ اسکن‌ها حداقل IP و زمان پاسخ را ذخیره می‌کنند؛ ستون‌های دیگر به چیزی که پروب اندازه می‌گیرد بستگی دارند.

| نوع اسکن | ستون‌های CSV |
| --- | --- |
| ICMP | `ip, latency, tries, mode` |
| TCP | `ip, latency, port, tries` |
| HTTP | `ip, latency, status, version, tls` |
| Xray | `ip, latency, download, upload` |
| DNS Resolver | `ip, latency, record_type, tries, rcode, dpi_check` |
| DNSTT | `ip, latency, transport, port, auth, proxy` |
| VayDNS | `ip, latency, transport, port, auth, proxy` |
| Slipstream | `ip, latency, port, auth, proxy` |

- `ip` — آدرس IPv4 یا IPv6 که پاسخ داده است.
- `latency` — زمان رفت‌وبرگشت یا زمان اتصال، مثل `123ms`.
- `download` و `upload` — سرعت دانلود و آپلود Xray بر اساس بیت بر ثانیه؛ اگر تست مربوطه فعال نباشد، مقدار `0 bps` است.
- `status`، `version` و `tls` — کد وضعیت HTTP، نسخهٔ توافق‌شدهٔ HTTP و این‌که TLS استفاده شده یا نه.
- `tries` — تعداد تلاش‌ها تا رسیدن به پاسخ.
- `mode` — نوع Socket در ICMP (`raw` یا `udp`).
- `rcode` و `dpi_check` — کد پاسخ DNS و نتیجهٔ بررسی ضد Hijacking.
- `transport` و `port` — روش انتقال DNS و پورت محلی SOCKS5 که برای پروب‌های تونل اختصاص داده شده است.
- `auth` و `proxy` — روش احراز هویت و نوع Proxyای که برای پروب تونل تنظیم شده است.

#### نمونهٔ HTTP

```csv
1.2.3.4,45ms,200,HTTP/2.0,true
2606:4700::6810:85e5,120ms,403,HTTP/1.1,true
```

#### نمونهٔ Xray

```csv
1.2.3.4,45ms,0 bps,0 bps
5.6.7.8,120ms,10.00 Mbps,5.00 Mbps
```

در اسکن‌هایی که سرعت را اندازه نمی‌گیرند، ستون‌های دانلود و آپلود وجود ندارند.

## ترتیب نتیجه‌ها

IPهای هر فایل بر اساس امتیاز کیفیت مخصوص همان Schema مرتب می‌شوند؛ امتیاز بالاتر یعنی نتیجه بهتر است. هر نوع اسکن تابع `Score()` خودش را دارد:

- **ICMP، TCP، HTTP، DNS، DNSTT، VayDNS و Slipstream:** امتیاز از معکوس زمان پاسخ (`1000 / latency_ms`) به دست می‌آید؛ بنابراین IPهای کم‌تأخیرتر بالاتر قرار می‌گیرند.
- **Xray:** امتیاز ترکیبی از تأخیر (۱۰٪)، سرعت دانلود (۶۰٪) و سرعت آپلود (۳۰٪) است. اگر تست سرعت خاموش باشد، سهم آن صفر می‌شود و اسکن فقط بر اساس تأخیر مرتب می‌شود.

هنگام ادغام نتیجه‌های جدید با فایل قبلی، فایل‌نویس آن‌ها را دوباره بر اساس امتیاز مرتب می‌کند و برای IP تکراری، نتیجهٔ جدیدتر را نگه می‌دارد. اگر امتیازها برابر باشند، ترتیب قبلی حفظ می‌شود.
