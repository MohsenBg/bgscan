# لاگ‌ها

BGScan دو نوع لاگ ثبت می‌کنه: یکی مربوط به هسته اسکنر و دیگری مربوط به رابط ترمینالی. هر دو رو می‌تونید به‌صورت زنده از داخل TUI ببینید.

برای دسترسی به لاگ‌ها، از منوی اصلی وارد **Main Menu → Logs** بشید.

## انواع لاگ

| کلید | بخش | توضیح |
|---|---|---|
| `c` | Core Logs | فعالیت‌های هسته اسکنر، مثل اجرای پروب‌ها روی IPها، عملیات فایل، ذخیره نتیجه‌ها و خطاهای داخلی |
| `u` | UI Logs | رویدادهای رابط کاربری، مثل چرخه عمر کامپوننت‌ها، عملیات فایلی که از داخل TUI شروع می‌شن و خطاهای مربوط به رابط |

کلید مربوط به هر بخش رو بزنید تا لاگ‌های اون رو ببینید.

## سطح لاگ

هر دو نوع لاگ از مقدار `log_level` در فایل `settings/ui_settings.toml` استفاده می‌کنن:

```toml id="8v4m2k"
log_level = "info"
```

مقدارهای مجاز عبارت‌اند از `debug`، `info`، `warn` و `error`.

این مقدار هنگام شروع برنامه روی هر دو Logger اعمال می‌شه. اگه از مسیر **Settings → UI Settings** تغییرش بدید، تنظیم جدید همون لحظه اعمال می‌شه و نیازی به راه‌اندازی مجدد BGScan نیست.

سطح `debug` جزئیات بیشتری از جمله خطاهای پروب همراه با IP کامل هدف ثبت می‌کنه. این سطح برای عیب‌یابی مفیده، اما حجم لاگ‌ها رو هم افزایش می‌ده. سطح پیش‌فرض `info` هست.

## نمایش لاگ‌ها

هر نمایش‌دهنده، فهرستی قابل اسکرول از پیام‌های زمان‌دار همون بخش رو نشون می‌ده. پیام‌های جدید هم تا وقتی نمایش‌دهنده بازه، به‌صورت خودکار اضافه می‌شن. بنابراین نیازی به Refresh دستی نیست.

قالب هر خط لاگ به این صورته:

```text
2006/01/02 15:04:05 [LEVEL] message
```

سطح‌های پیام شامل `INFO`، `WARN`، `ERROR` و `DEBUG` هستن. پیام‌هایی که نمایش داده می‌شن، به مقدار `log_level` بستگی دارن.

هنگام باز شدن نمایش‌دهنده، ۲۰۰ خط آخر فایل لاگ خونده می‌شه تا بتونید فعالیت‌های اخیر رو همون ابتدا ببینید، حتی اگه اتفاق جدیدی نیفتاده باشه.

### کلیدهای حرکتی

| کلید | عملکرد |
|---|---|
| `↑` / `↓` | حرکت به بالا و پایین در فهرست |
| `b` یا `Esc` | بستن نمایش‌دهنده |

## محل ذخیره فایل‌های لاگ

فایل‌های لاگ در پوشه `logs/`، کنار باینری BGScan ذخیره می‌شن:

```text
<bgscan-root>/
└── logs/
    ├── core.log
    └── ui.log
```

فایل‌های لاگ به‌صورت خودکار Rotation می‌شن تا فضای زیادی اشغال نکنن. محدودیت‌ها به این صورته:

- حداکثر حجم هر فایل: **۵۰ مگابایت**
- تعداد فایل‌های پشتیبان: حداکثر **۳ فایل**
- حذف فایل‌های قدیمی‌تر از **۷ روز**
- فشرده‌سازی فایل‌های پشتیبان قدیمی‌تر برای کاهش مصرف فضا

اگه بخواید خارج از TUI لاگ‌ها رو بررسی کنید، می‌تونید فایل‌ها رو با هر ویرایشگر متنی باز کنید یا از دستور `tail -f` برای مشاهده زنده پیام‌ها استفاده کنید.
