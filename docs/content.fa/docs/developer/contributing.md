# راهنمای مشارکت

ممنون که می‌خواید به **BGScan** کمک کنید. چه باگ رفع کنید، چه مستندات رو بهتر کنید یا قابلیت جدیدی اضافه کنید، مشارکت شما به بهتر شدن پروژه کمک می‌کنه.

## قبل از شروع

- قبل از باز کردن Issue جدید، Issueهای موجود رو بررسی کنید تا مطمئن بشید موضوع قبلاً مطرح نشده.
- اگه قصد دارید قابلیت بزرگی اضافه کنید یا تغییر مهمی بدید، بهتره اول یک Issue باز کنید و درباره راه‌حل پیشنهادی صحبت کنید.
- سعی کنید هر Pull Request روی یک تغییر مشخص متمرکز باشه.

---

## استراتژی Branch

لطفاً **مستقیم روی `main` کامیت نکنید**. برای تغییراتتون یک Branch جدا بسازید:

```bash
git checkout main
git pull origin main
git checkout -b feature/my-feature
```

برای نام‌گذاری Branch می‌تونید از این الگوها استفاده کنید:

```text
feature/add-xray-parser
feature/ui-improvements
fix/memory-leak
fix/windows-build
docs/update-readme
refactor/scanner
test/unit-tests
```

---

## سبک کدنویسی

- از قراردادها و الگوهای موجود در پروژه پیروی کنید.
- کد رو ساده و خوانا بنویسید.
- تغییرات رو به Commitهای کوچک و مشخص تقسیم کنید.
- از تغییرات قالب‌بندی نامرتبط با کارتون خودداری کنید.
- فقط جایی کامنت بذارید که به فهم بهتر کد کمک می‌کنه.

---

## پیام Commit

پیام Commit باید کوتاه و مشخص باشه و توضیح بده چه تغییری انجام شده.

چند نمونه:

```text
feat: add HTTP/3 support
fix: resolve race condition in scanner
docs: improve installation guide
refactor: simplify writer pipeline
test: add unit tests for parser
```

---

## Pull Request

قبل از باز کردن Pull Request، این موارد رو بررسی کنید:

- پروژه بدون خطا Build می‌شه.
- تست‌های موجود با موفقیت اجرا می‌شن.
- قابلیت جدید، در صورت نیاز، تست مناسب داره.
- مستندات مرتبط با تغییرات به‌روز شدن.

در توضیحات Pull Request هم لطفاً این موارد رو بنویسید:

- چه چیزی تغییر کرده؟
- چرا این تغییر لازمه؟
- در صورت تغییر رابط کاربری، اسکرین‌شات یا تصویر مناسبی اضافه کنید.
- اگه Issue مرتبطی وجود داره، بهش لینک بدید.

---

## گزارش باگ

برای اینکه بررسی و رفع باگ راحت‌تر باشه، تا جای ممکن این اطلاعات رو در Issue بنویسید:

- سیستم‌عامل
- معماری سیستم
- نسخه BGScan
- تنظیمات مرتبط
- مراحل بازتولید باگ
- رفتار مورد انتظار
- رفتار واقعی برنامه
- لاگ‌های مرتبط، در صورت وجود

هرچه اطلاعات دقیق‌تری ارائه بدید، پیدا کردن علت مشکل راحت‌تر می‌شه.

---

## درخواست قابلیت

اگه می‌خواید قابلیت جدیدی پیشنهاد بدید، بهتره این موارد رو توضیح بدید:

- چه مشکلی دارید و این قابلیت قراره چه چیزی رو حل کنه؟
- چه راه‌حلی پیشنهاد می‌کنید؟
- آیا راه‌حل جایگزین دیگه‌ای هم وجود داره؟
- چه اطلاعات یا جزئیات دیگه‌ای می‌تونه به بررسی پیشنهاد کمک کنه؟

---

## آیین‌نامه رفتار

با بقیه محترمانه و سازنده برخورد کنید. از بحث و تبادل نظر سالم استقبال می‌کنیم، اما توهین شخصی، آزار و رفتار بی‌احترام قابل قبول نیست.

ممنون که برای بهتر شدن BGScan وقت می‌ذارید!
