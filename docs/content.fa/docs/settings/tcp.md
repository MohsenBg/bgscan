# تنظیمات TCP

> 💡 **نکته:** از **Settings → TCP Settings** هم می‌توانید این گزینه‌ها را تغییر دهید.

فایل تنظیمات: `settings/tcp_settings.toml`

پروب TCP به یک پورت روی هر هدف وصل می‌شود و زمان TCP Handshake را ثبت می‌کند. هیچ پروتکل لایهٔ کاربردی را اجرا نمی‌کند.

## خلاصهٔ گزینه‌ها

| گزینه | پیش‌فرض | محدوده | توضیح |
|---|---:|---|---|
| `port` | `443` | 1-65535 | پورت TCP هدف |
| `timeout` | `2000` | 100-30000 | زمان اتصال، میلی‌ثانیه |
| `workers` | `400` | 1-10000 | اتصال‌های هم‌زمان |
| `tries` | `1` | 1-10 | تعداد تلاش برای هر هدف |
| `prefix_output` | `"tcp_"` | | پیشوند فایل نتیجه |

## Port

```toml
port = 80
```

پورتی که روی همهٔ هدف‌ها بررسی می‌شود. انتخاب‌های رایج 80، 443 و 22 هستند.

## Timeout

```toml
timeout = 3000
```

مدت انتظار برای Handshake بر حسب میلی‌ثانیه است. هدفی که در این زمان اتصال را کامل نکند، غیرقابل‌دسترسی حساب می‌شود.

- `1000-3000` برای شبکه‌های نزدیک
- `5000-10000` برای شبکه‌های دور یا ناپایدار

## Workers

```toml
workers = 200
```

تعداد اتصال‌های هم‌زمان. هر Worker یک Socket باز نگه می‌دارد، پس مقدار بالا به File Descriptor limit مناسب نیاز دارد.

- `50-100` برای سیستم‌های محدود
- `200-500` برای استفادهٔ معمول
- `500-1000` برای اسکن پرسرعت

## Retries

```toml
tries = 1
```

تعداد تلاش قبل از رهاکردن هدف است. فقط Timeout دوباره تلاش می‌شود. Connection refused یا خطای فوری، همان لحظه هدف را ناموفق می‌کند تا محدوده‌های مرده سریع‌تر تمام شوند. حداقل مقدار ۱ است و تلاش اول را نمی‌توان خاموش کرد.

## Prefix Output

```toml
prefix_output = "tcp_"
```

پیشوند فایل‌های نتیجهٔ این پروب است. فایل‌ها داخل `result/tcp/` می‌روند.
