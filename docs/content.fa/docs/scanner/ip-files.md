# فهرست‌های IP

اسکنر آدرس‌های هدف رو از فایل‌های IP می‌خونه. برای استفاده از یه فهرست، باید اون رو آماده کنید و وارد bgscan کنید.

---

## آماده‌کردن فایل برای ورود

فایل ورودی باید یه فایل متنی ساده با پسوند `.txt` باشه که **هر ورودی توی یه خط جدا** قرار بگیره. هم آدرس‌های IPv4 و IPv6 پشتیبانی می‌شن و هم رنج‌های CIDR.

| قالب | مثال |
|---|---|
| آدرس IPv4 | `192.168.1.1` |
| رنج IPv4 با CIDR | `10.0.0.0/24` |
| آدرس IPv6 | `2606:4700::6810:85e5` |
| رنج IPv6 با CIDR | `2606:4700::/32` |

**قواعد فایل ورودی:**

- هر خط باید فقط یه ورودی داشته باشه. چند آدرس رو توی یه خط ننویسید.
- خط‌های خالی و ورودی‌هایی که آدرس IPv4، IPv6 یا CIDR معتبر نیستن، بدون نمایش خطا رد می‌شن.
- فایل از کامنت پشتیبانی نمی‌کنه. حتی خط‌هایی که با `#` شروع می‌شن هم رد می‌شن.
- فاصله‌های ابتدا و انتهای هر خط به‌صورت خودکار حذف می‌شن.

> **درباره رنج‌های بزرگ IPv6:** یه پیشوند مثل ` /32` بیش از 2^96 آدرس داره. bgscan رنج‌های CIDR رو هنگام اسکن باز می‌کنه، اما اسکن کامل چنین رنج بزرگی عملاً شدنی نیست. برای محدود کردن تعداد آدرس‌هایی که بررسی می‌شن، مقدار `max_ips_to_test` رو در [تنظیمات عمومی](../settings/general.md) تنظیم کنید.

### نمونه فایل ورودی

```
192.168.1.1
10.0.0.0/24
172.16.50.100
203.0.113.0/28
2606:4700::6810:85e5
2606:4700::/32
```

## فهرست‌های داخلی

bgscan چند فهرست IP آماده هم داخل پوشه `ips/` داره. این فهرست‌ها به‌صورت خودکار بارگذاری می‌شن و برای استفاده از اون‌ها نیازی به تنظیمات اضافی نیست.

| نام | توضیح |
|---|---|
| `akamai_IPv4` | رنج‌های IPv4 آکامای |
| `aws_IPv4` | رنج‌های IPv4 آمازون وب سرویس |
| `azure_IPv4` | رنج‌های IPv4 مایکروسافت آژور |
| `bunny_IPv4` | رنج‌های IPv4 سرویس Bunny CDN |
| `cloudflare_IPv4` | رنج‌های IPv4 کلادفلر |
| `cloudflare_IPv6` | رنج‌های IPv6 کلادفلر |
| `cloudflare_ipv6_known` | رنج‌های IPv6 سالم و شناخته‌شده کلادفلر |
| `cloudflare_common_IPv6` | رنج‌های رایج IPv6 کلادفلر |
| `cloudflare_full_IPv6` | تمام رنج‌های IPv6 کلادفلر |
| `fastly_IPv4` | رنج‌های IPv4 فستلی |
| `gcore_IPv4` | رنج‌های IPv4 جی‌کور لبز |
| `google_IPv4` | رنج‌های IPv4 گوگل |
| `iran_IPv4` | آدرس‌های IPv4 ایران |
| `pub_dns_IPv4` | آدرس‌های IPv4 سرورهای DNS عمومی |

فهرست‌های داخلی هم از همون قالب CSV استفاده می‌کنن و می‌تونید مثل بقیه فهرست‌ها تغییر نامشون بدید یا حذفشون کنید.
